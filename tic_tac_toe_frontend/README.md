# Tic Tac Toe Frontend (React)

A responsive, modern light-themed Tic Tac Toe UI (local two-player).

## Requirements
- Node.js 18+

## Run (dev)
```bash
npm install
npm start
```

The app uses `REACT_APP_PORT` (from `.env`) to select the dev server port (default 3000).

## Build
```bash
npm run build
```
